## Notes

- **Status** values: `active` (content current), `outdated` (needs review), `archived` (model deprecated).
- A source is considered **outdated** if it has not been checked within 90 days or if the linked content has materially changed.
- Refs in this file use the `G` prefix to avoid collision with the provider-scoped registries ([openai.md](openai.md), [google.md](google.md)).
